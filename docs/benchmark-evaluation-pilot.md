# Benchmark evaluation pilot — 16 September 2026

Ran `benchmark_evaluation_v1` on the same 12 recipe reconstruction enabled profiles as the earlier larger-budget pilot. Each model was regenerated by replaying its recorded training recipe. Original service metrics were unchanged, and no client checkpoint was read. This is a separate evaluation report, not a backfill of the source catalogues.

The pilot used 32 trust inputs × 4 perturbations and 16 explanation inputs with 4 random controls per masking amount and replacement. Explanation retained up to 32 candidate groups, three masking amounts and two replacements. Trust required at least 16 independent successful inputs; explanation required 8. The maximum 95% interval width was 0.15. The historical table below retains the original results; the final policy and replacement review follow it.

Targets are capped by eligible independent rows before evaluation. Each source/document/patient component contributes at most one selected row. Unsupported interventions and failed inputs are recorded without shrinking the frozen target. No rows were duplicated to meet a target.

CPU execution used two workers with four threads each and stage limits of 600 seconds for trust and 1,800 seconds for explanation. A single in-flight inference can exceed a deadline. Durations include recipe reconstruction, dataset preparation and concurrent resource contention.

No new task adapters or text transformations were developed. The causal-LM data still lacks a valid prompt boundary; unvalidated text trust transformations remain unsupported. Any other exclusions and precision failures are retained in the evidence rather than filled with a neutral score.

The benchmark synthetic control run passed all eight checks: known-feature explanations beat random and reversed rankings; constant predictors stayed stable with zero faithfulness and poor task quality; fragile predictors lost stability; model randomization changed rankings; all requested trial budgets completed. These are directional sanity checks, not a universal validity claim.

Validation: **792 repository tests passed**, including independent-row caps, 16/8 evidence floors, frozen manifest overrides, completed-service skip behavior, missing scores, storage and protocol-specific composition gates.

To apply the preset to unfinished rows of an existing manifest, stop normally and resume the same command with `--metric-evaluation-profile benchmark`. No new manifest is required. Frozen training settings, seeds and service IDs are preserved, and completed IDs stay skipped. Restarting without the flag retains any explicit or frozen old metric settings. Completed rows need a separate evaluation pass to obtain new evidence.

## Final budget and replacement review

The final benchmark policy treats 32/16 as maximum evaluation budgets. Evidence
requires at least 16/8 independent successful inputs, at least 80% input coverage
and 80% trial coverage against the frozen effective budget, and the existing
maximum 95% CI width of 0.15. Each failed gate records observed and required
values, alongside the concrete exclusion/failure reasons.

Reaggregating the existing, hash-verified pilot trials admits digits trust
(31/32 inputs, 96.9% coverage) and diabetes trust (28/32, 87.5%). Wine trust still
fails the count floor (12 < 16) and coverage (66.7%). Wine and diabetes
explanations still fail precision; WikiANN still fails count and coverage.
Unsupported task contracts remain unsupported. This is a separate analysis of
existing evidence, without rerunning models or changing stored catalogue rows.

**Use only empirical replacement for the benchmark default.** Comparing the
same frozen empirical trials with the two-method aggregate changes no profile's
explanation evidence status. Across the 11 profiles with measured explanation
scores, the maximum absolute aggregate-score change is 0.01911. Mean/mask
replacement does not repair the WikiANN ranking/alignment failures. Keep both
methods available explicitly and as the defaults for diagnostic/pilot/production
profiles when replacement sensitivity is part of the experiment.

Removing the second method reduces validation sets from 24 to 12 per input and
validation prediction examples from 144 to 72. With 32 ranking groups plus a
baseline, that is about 41% less prediction work per fully evaluated input.
The original explanation stages took 527.8 seconds for DeiT/beans and 1,067.9
seconds for FLAN-T5/XSum, making this reduction useful. The pilot did not time
each method independently, so the 41% figure is an inference-work estimate,
not a measured wall-clock speedup.

The final single-method synthetic run passed all eight directional checks:
known-feature faithfulness 0.4519, random and reversed rankings 0, constant
predictor trust 1 with faithfulness 0, and fragile predictor trust 0.4688.

Final validation: **818 repository tests passed**, including independent count,
coverage and precision failures, deadline sufficiency, frozen-plan resume checks,
single-method trial reuse, and terminal scores/times/reasons.
